# TechNote

Explain the result in the requested language; otherwise use English. Default to Level 1. A simple answer needs no report form, and the user may request any level directly.

## Level 1 — Technical note

Lead with the result. Add the evidence and limits needed to assess it, and a next action only if work remains. Distinguish observed behavior, proposed choices and unknowns without mandatory labels. State actual checks when relevant; source or build success does not prove runtime behavior.

Omit unchanged context, empty fields, repeated approval references and full logs. Keep a checkpoint only when continuation needs it. Explanation does not create delivery phases or permission.

## Level 2 — Diagrams

When selected, show the relevant actors, data or decisions. Label hypothetical behavior.

## Level 3 — Interactive explanation website

When selected, deliver a working interactive explanation and check its navigation/replay. Label simulation.

## Level 4 — Explanation video

When selected and feasible, deliver an actual checked video; a script is not a video.

Read the [extended method](technote-reference.md) for medium-specific guidance. Publication and sensitive capture need their actual authority. Explain capability limits honestly.
