# Task records and checkpoints

A focused fix needs no new task file if the request, diff, relevant checks and short handoff suffice. Use an existing tracker when the project requires one or coordination benefits. No mandatory per-phase plan, state ledger, receipt or Coordinator.

For a long, delegated or cross-session task maintain **one current checkpoint**: outcome/acceptance/scope, completed and remaining work, decisions/latest stop, revision, actual PASS/FAIL/NOT_RUN checks and limits, blocker/owner and next action. Update at meaningful milestones, not after every command. Preserve historical approvals and evidence. A record never grants permission or proves human acceptance/release.
