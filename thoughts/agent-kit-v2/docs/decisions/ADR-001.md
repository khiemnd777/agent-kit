# ADR-001 — Independent decision and execution layers

Date: 2026-11-17
Architecture status: ACCEPTED by the user in the source conversation.
Implementation boundary: Agent Kit V2 only; Sidecar deferred.

## Decision

**Agent Kit — Decision & Governance -> Sidecar — Execution & Optimization.**

Separate repositories coordinate through an explicit execution contract.
The coding agent following Agent Kit owns goals, scope, risk, authorization,
acceptance interpretation, reasoning and human handoff. A future independent
executor owns internal workflow execution, concurrency, bounded safe handling,
optimization and evidence. It does not own human approval or product intent.

Delegate complete repeatable blocks at the time they are ready, including task
entry and intermediate stable subproblems. Do not limit delegation to final tests
or require an LLM decision between fixed execution steps.

## Required properties

Autonomous execution within delegated bounds; exception-driven reasoning;
measured optimization; independent repositories; actual human authority.
Agent Kit may change to cooperate. Repository independence does not mean Agent
Kit must remain untouched, nor that its governance can be bypassed.

## This package

V2 implements the instruction/skill layer and draft contract definitions plus
offline package validation. It contains no runtime executor, registry, DAG engine,
connector, scheduling or Sidecar code. Contract details are a reviewable V2 draft,
not a claim of implemented interoperable software.

## Consequences

Known work should not repeatedly pass through LLM orchestration. Novel reasoning
still has a cost. Existing scripts/CI remain valid alternatives. Benefits must
be measured separately from reductions in documentation size. Swamp was an
architectural reference in the discussion; no Swamp source is imported here.
