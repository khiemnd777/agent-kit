# documentation-and-adrs

Use the project's existing documentation conventions. Record enduring context, decision, major alternatives, consequences and practical usage/operation. Update affected public contracts alongside the change. Do not generate a new ADR or README section for every implementation step.

Use the [extended patterns](references/extended.md) only when their details are relevant.
