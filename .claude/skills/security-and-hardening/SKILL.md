# security-and-hardening

Trace the actual authenticated actor, resource and tenant ownership, untrusted input and data flows. Apply existing project controls for validation, injection/SSRF, session/CSRF, secrets, uploads, privacy and dependencies **where affected**. Test denied and misuse paths that could regress. Preserve established policy and never weaken tests, permissions or data protections for faster output.

Read the [extended patterns](references/extended.md) only for relevant techniques and examples.
