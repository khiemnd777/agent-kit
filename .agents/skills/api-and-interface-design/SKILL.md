# api-and-interface-design

Define the changed consumer/owner contract, input validation, error semantics and backward compatibility. Address pagination, idempotency and authorization only when those seams are affected. Implement real consumers and verify targeted contract/error paths. Do not redesign stable interfaces as a task ritual.

Read the [extended patterns](references/extended.md) only for relevant techniques and examples.
