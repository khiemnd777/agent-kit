# performance-optimization

Record baseline conditions and actual target. Identify the bottleneck using existing profiling/measurements; fix the owning seam. Re-measure comparable inputs, classify failing checks and keep only improvements that preserve correctness. Do not add mandatory RUM/CI/benchmark infrastructure or revert blindly after unrelated red checks.

Read the [extended patterns](references/extended.md) only for relevant techniques and examples.
