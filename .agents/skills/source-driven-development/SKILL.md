# source-driven-development

Identify the specific unknown, resolve project version and pinned dependencies, consult authoritative version-matched source, then apply only the relevant documented pattern. Report source and remaining uncertainty. Ordinary edits that preserve supported project conventions need no research workflow.

Use the [extended patterns](references/extended.md) only when their details are relevant.
